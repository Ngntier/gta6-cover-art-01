**Neon Coast Cover Studio** — an offline web app that turns any photo and a caption into GTA-style multi-panel cover art, in the Vice City sunset / neon look, exported as a PNG to share.

Pick a layout (Panel Grid, Hero + Three, Tilted Snapshots, Full Bleed, Nine-Panel Mosaic), drop in your own photos or use the two built-in samples, crop and position each panel, choose a gradient-map sunset grade, set the big Anton title with a neon Pacifico subtitle, heat-meter stars and badge ribbon — then export in the common post sizes: 1080 × 1080, 1080 × 1350, or 1920 × 1080. Undo/redo included. Everything runs offline in the browser; photos never leave your machine. All lettering uses SIL Open Font License fonts (Anton, Pacifico) shipped under `app/fonts/`; no Rockstar logo, artwork, or font is used anywhere.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add photos, pick a layout and grade, edit the title, and hit **Export PNG**.
